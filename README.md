## Overview
MetaFed is a multi-tier application that enables structured data flow between frontend, backend, database, and machine learning services.

## My Contribution

## Tech Stack
- React.js (Frontend)
- Node.js, Express.js (Backend)
- Flask (ML Service)
- PostgreSQL (Database)

## Features
- Multi-tier architecture system
- API-based communication between services
- Real-time data processing flow
- Integration with prediction service

## Architecture Flow
1. User inputs data through frontend  
2. Data is sent to backend APIs  
3. Backend processes and forwards data to ML service  
4. ML service returns prediction  
5. Backend sends response to frontend
